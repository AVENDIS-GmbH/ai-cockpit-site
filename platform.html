Platform

A frame for AI work, neutral to what runs in it.

The platform delivers structure, control and proof. What a process checks, with which knowledge and which model, is configuration.

Concept model

Eleven terms define the product.

Everything else follows from them. Each exists as data, so each can get a screen.

Area
Organisational frame. Bundles processes, data sources and permissions. Hierarchical.
Process
Definition of a recurring task: input form, agent, workflow, knowledge, output template, model.
Agent
The executing unit with prompts, tools and model requirements. Exchangeable behind a fixed contract.
Workflow
States and allowed transitions. Defines where the machine acts and where a person does.
Case
One concrete instance of a process, moving through the states of its workflow.
Run
One execution of an agent for a case. Numbered; a case can have several rounds.
Ruleset
Versioned knowledge that is checked against. Maintained on its own, released before it takes effect.
Data source
Supplies context for a run behind one interface; the implementation can change.
Output template
The form the structured result is brought into. Separate from the content.
Model
A language model with its properties and where it is operated. Behind a gateway, exchangeable.
Audit trail
Complete record of every state change with author, time and reason.
That is the whole list
A new process is a new combination of these terms, not a new concept.

Principles

The rules the platform is built by.

Configuration over programming

What changes with the business is data. What is data can get a user interface later.

Exchangeable behind contracts

Agents, models and data sources are defined by their interface, not by their implementation.

Deterministic output

Agents return structured data. No second language model stands between result and report.

The human decides

The system proposes, prepares and executes. Evaluating steps belong to a person and are logged.

Reconstructable

A result is fully described by what went into it: inputs, model, ruleset version, time.

One source of truth

One database holds business data, configuration, audit trail and the job queue. One thing to back up.

Architecture

Three containers. Everything else is attached.

The delivery is a Compose file with the application, the database and the agent runtime. Model gateway and document conversion are services you may already run; the platform knows only their address.

Delivered

Application

User interface, API and the worker that drives runs. One application, no separate backend.

Delivered

Database

PostgreSQL. Cases, configuration, rulesets, audit trail and the queue for long runs.

Delivered

Agent runtime

Stateless service that executes the agent logic behind one contract: start a run, return a structured result.

Attached

Model gateway

One OpenAI-compatible access to all models, local or in a region of your choice.

Attached

Document conversion

Turns PDF and Word files into text the agent can read.

Prepared

Identity provider

Sign-in is prepared for an external identity provider.

No vector store, no object store, no cache service in the basic setup. Each additional component has to justify the effort of operating it.

Boundaries

What the platform is not.

These are not gaps. A bounded process that provably runs right is what a compliance officer can answer for.

Not a chat productDialogue is one way into the platform, not its purpose.
Not a model providerModels are attached, not supplied.
Not a development environmentAgent logic is written outside; the platform operates and controls it.
Not general automationThe subject is knowledge work with human responsibility, not system integration.
Not free chainingUsers do not wire blocks into flows of their own. There are released patterns; what is configured is their content.
