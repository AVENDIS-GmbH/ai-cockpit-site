# ai-cockpit

**AI-assisted business processes that stand up to an audit.**

ai-cockpit is a platform on which business units hand recurring, knowledge-based work to AI
agents — configured instead of programmed. An agent does the work, a person decides at defined
points, and every decision is on record with author, time and reason.

**→ [avendis-gmbh.github.io/ai-cockpit-site](https://avendis-gmbh.github.io/ai-cockpit-site/)**

![The board of ai-cockpit: cases of all processes in stage columns](assets/img/board.png)

## What sets it apart

- **Decisions carry a reason.** Approval, return and withdrawal are logged with who, when and why.
- **Knowledge is versioned.** The rules an agent checks against are maintained and released, not
  buried in a prompt.
- **Results can be reconstructed.** Every run records its inputs, its model and its ruleset version.
- **It runs in your house.** On-premises by design, with a model you choose and can exchange.

## Where it stands

In active development, not released for production use.

**Today** — one process runs end to end: the legal pre-review of framework contracts. An agent
checks a contract against a catalogue of 32 checkpoints, a reviewer approves or returns the
result, and the report goes into the company's Word template. Around it: one board for all
processes, versioned rulesets with a curation process, an audit trail, roles per area, model
administration and token usage.

**Next** — more processes on the same pattern, administration of agents and data sources,
process templates, single sign-on.

**Later** — self-service: customers set up their own processes.
